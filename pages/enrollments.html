    How to Import Learners

    Add learner records and enroll them in the selected school year and section. Choose the method that matches your starting point.

    Before you begin

    Use your SF1 form in Excel (.xlsx) format to import learners. Check the target School Year, Grade Level, and Section before importing. If any of these records are missing, contact your administrative staff for assistance.

    Upload File

    Use this when you already have a LIS/SF1 learner file.

    1. Choose Upload File, then drop or select a .csv or .xlsx file.
    2. Check the detected file details, then select Next: Review & Edit.
    3. Confirm the school year, grade level, and section. Review the learner rows and correct any highlighted values or reported issues.
    4. Select Confirm & Import when ready to save the learners. Wait for the import to finish.
    5. Check the Imported, Skipped, and Failed totals to review the outcome.

    Spreadsheet Entry

    Use this to type or paste learner data into the page.

    1. Choose Spreadsheet Entry and select the school year, grade level, and section.
    2. Select Next: Enter Learner Data.
    3. Enter one learner per row. Match pasted values to the column headings. Use Add Rows for more space.
    4. Review the entries, then select Validate & Import. This checks the data and starts saving if validation passes.
    5. Fix any highlighted cells or reported issues and try again. After completion, review the import summary before adding more learners.

    How promotion checks work during import

    For an existing learner entering a new school year, the import checks their latest earlier enrollment before accepting the target grade.

    • With a promotion record: the selected grade must match its recommendation. Import is blocked for Retained, Conditionally Promoted, or Completed with no next grade.
    • Without a promotion record: Grades 2-10 use subject offerings, complete passing numeric final grades, and a general average of at least 75. Grade 1 descriptive mode instead requires every PACE A-E rating for Terms 1-3; numeric final grades and a general average are not required. The selected grade must match the expected next grade when one is configured.
    • No earlier enrollment: an existing learner receives a warning and can receive a new school-year enrollment if the other checks pass.
    • Reimporting an existing learner: when the School Year and Grade Level are the same but the section is different, completing the import updates the existing enrollment and moves the learner from the previous section to the selected section. The review message shows the move (for example, Section A → Section B). If the section is also the same, the import refreshes personal details.
    • If blocked: read the row’s message. Ask your registrar or administrator to verify the promotion status, complete academic records, or correct the target grade before retrying.

    External Returnee / Balik-Aral rows

    The imported LIS/DepEd source record is authoritative when Remarks is present. A row marked Balik-Aral or Returnee is enrolled for the new school year with Entry Classification: Returnee. The previous enrollment is kept unchanged.

    • The target enrollment status is Enrolled and its enrollment type is Balik-Aral.
    • If Remarks is blank, the importer checks the latest prior grade record. Same-grade re-entry with missing or failing final grades is treated as Returnee; otherwise promotion checks apply.
    • The import does not infer returnee status from a school-year gap and does not create a pending approval step.
    • Review the stored Entry Classification and Enrollment Status in the standard Enrollments list; no separate review or approval page is required.

    Transfer-In rows

    Use Transferred In, Transfer-In, T/I, or TI in the source Remarks column. The learner will be enrolled here as Transfer-In without using local promotion history.

    • The learner’s LRN remains the single learner record.
    • The new enrollment is stored as Enrolled / Transfer-In.
    • Previous-school details can be entered manually in Learner Registration → Previous School Information when the school needs the history displayed locally.
    • Previous grades can be entered manually in SF10 → Previous-school records; they remain separate from this school’s report-card grades and are not an import requirement.

    Source status handling

    The imported LIS/SF1 status is authoritative. The app stores the status and applies its local roster/report behavior; it does not repeat external document or previous-school grade checks.

    • T/O or Transferred Out marks the enrollment as Transferred Out and preserves its history.
    • DRP, Dropped, or Dropped Out marks the enrollment as Dropped for consolidated reporting.
    • LE or Late Enrollment keeps the learner Enrolled with Entry Classification: Late Enrollment.
    • LWD is stored as a separate BoSY learner identifier and does not change enrollment or grade-entry eligibility.

    Need help with a message?

    • Missing columns or invalid values: check the named column or row. Keep the file’s column headings, correct the data, and upload again if needed.
    • Duplicate or existing learner: check the LRN and the reported result before importing again. Do not change an LRN just to bypass a duplicate message.
    • Section capacity or promotion issue: verify the selected grade and section with your registrar or administrator.
    • Skipped or failed rows: these are not counted as successfully imported. Read their messages and check existing records before retrying.
